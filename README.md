# 🛡️ CipherWatch

> Real-time cybersecurity threat detection and monitoring platform.

## Features
- 🔍 Phishing link & email detection
- 🌐 Network vulnerability scanning
- 🚨 Real-time threat alerts
- 📊 Security dashboard & reports
- 🤖 AI-powered threat classification

## Tech Stack
- **Frontend:** React + TailwindCSS
- **Backend:** Python (FastAPI)
- **AI:** Claude API
- **Database:** PostgreSQL
- **Cache:** Redis
- **Deploy:** Docker + AWS/Vercel

## Getting Started
\`\`\`bash
git clone https://github.com/prezzo43-spec/cipherwatch.git
cd cipherwatch
